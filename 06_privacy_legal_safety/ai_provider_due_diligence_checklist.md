# AI Provider Due Diligence Checklist

Current status: due-diligence checklist only. This document does not approve AI provider use, implementation, public MVP build, production readiness, or legal/privacy/security compliance claims.

No live beta user data may be sent to any AI provider before approval is recorded by the owner and relevant privacy/legal/security reviewers.

## Provider Review

| Check | Required evidence | Status |
|---|---|---|
| Provider identity and service scope documented | Provider name, service, models/features, intended beta use | Not started |
| Retention terms reviewed | Whether prompts, outputs, logs, files, embeddings, or metadata are retained and for how long | Not started |
| Logging terms reviewed | What provider logs, for what purpose, and for how long | Not started |
| Training-use terms reviewed | Whether beta data can be used for model training or improvement; opt-out availability | Not started |
| Deletion process reviewed | How deletion requests propagate to provider-held data and logs | Not started |
| Subprocessors reviewed | Subprocessor list, purpose, and change notification process | Not started |
| Cross-border transfer reviewed | Where data may be processed or stored | Not started |
| Data minimisation plan reviewed | Minimum fields sent to provider for each beta use | Not started |
| Opt-out and feature fallback reviewed | Whether users can avoid provider processing or specific data categories | Not started |
| Incident response reviewed | Provider breach/security notification terms and support process | Not started |
| Security controls reviewed | Encryption, access controls, audit practices, relevant assurance materials if available | Not started |
| Contractual terms reviewed | Terms, data processing terms, confidentiality, liability, deletion, and usage restrictions | Not started |
| Sensitive data handling reviewed | Documents, photos, audio, video, wearable signals, support contacts, and reflections | Not started |
| Embedding/vector handling reviewed | Whether embeddings are created, retained, deleted, and isolated | Not started |
| Human review reviewed | Whether provider personnel may review prompts/outputs and under what conditions | Not started |

## Approval Gate

Live beta user data must not be sent to an AI provider until:

- Provider review is complete.
- Beta consent notice discloses provider processing.
- Data minimisation is approved.
- Deletion and retention handling is approved.
- Owner approval is recorded.
