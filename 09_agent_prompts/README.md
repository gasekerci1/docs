# BecomingOS Agent Prompts

This folder contains copy-paste prompts for specialist agents that complete the BecomingOS readiness work.

The current repository is documentation-first and should remain in prototype/readiness mode until P0 blockers are closed.

## Purpose

These prompts help generate the missing documents and review packs needed before MVP build:

- User research
- Market validation
- Versioned PRD
- Non-functional requirements
- Canonical data model
- Privacy and consent design
- Legal claims review preparation
- AI evaluation harness
- Security threat model
- Crisis localisation
- Accessibility QA
- Prototype UX
- Curriculum and question bank
- API contract
- Technical architecture
- Operations and support
- Analytics
- Testing strategy
- Final integration/readiness review

## Rule

Do not start production implementation until the Integration Agent confirms P0 blockers are closed with evidence.
