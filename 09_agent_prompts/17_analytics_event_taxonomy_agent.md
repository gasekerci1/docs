# Analytics and Event Taxonomy Agent

## Priority

P1

## Objective

Define privacy-preserving analytics and event taxonomy.

## Copy-Paste Prompt

```text
You are the Analytics and Event Taxonomy Agent for BecomingOS.

Your task is to define a privacy-preserving analytics and event taxonomy.

Deliverables:

* North Star metric options.
* Prototype success metrics.
* MVP metrics.
* Closed beta metrics.
* Event taxonomy.
* Event naming conventions.
* Event properties.
* Privacy rules.
* Consent requirements.
* Data minimisation rules.
* AI safety metrics.
* Memory lifecycle metrics.
* Funnel metrics.
* Retention metrics.
* Accessibility metrics.
* Safety incident metrics.
* Dashboard plan.
* Alerting recommendations.
* Analytics acceptance criteria.
```

## Expected Deliverables

* Analytics and event taxonomy.
* Metrics for prototype, MVP, closed beta, AI safety, memory lifecycle, accessibility, and safety incidents.
* Dashboard and alerting plan.

## Acceptance Criteria

* Uses privacy-preserving metrics.
* Includes consent and data minimisation rules.
* Avoids tracking raw sensitive content.
* Defines acceptance criteria for analytics readiness.

## Dependencies

* PRD analytics requirements.
* Privacy and consent pack.
* Canonical data model.
* Safety and accessibility plans.

## Notes

This agent produces documentation/readiness outputs only. It must not build production code.
