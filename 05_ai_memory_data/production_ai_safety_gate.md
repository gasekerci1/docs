# Production AI Safety Gate

Current status: production AI safety gate only.

Default status: not approved.

This document does not approve AI provider use, implementation, private beta, public MVP build, production readiness, public launch, or AI safety/compliance claims.

## Required AI Safety Gates Before Production

| Gate | Required evidence | Current status |
|---|---|---|
| AI role boundary | Production AI wording and behaviour keeps AI as draft support only, not therapist, clinician, emergency responder, professional adviser, or decision-maker. | Conceptual boundary exists; production evidence missing. |
| No therapy/diagnosis/treatment/crisis decisioning | Tests and review show AI does not provide therapy, diagnosis, treatment, crisis intervention, emergency monitoring, legal advice, medical advice, financial advice, addiction treatment advice, or professional replacement. | Missing |
| User confirmation for durable memory | Evidence shows nothing becomes durable memory without explicit user confirmation. | Conceptual rules exist; test evidence missing. |
| Rejected/deleted/unconfirmed exclusion | Evidence shows rejected, deleted, unconfirmed, expired, archived, and consent-withdrawn data is excluded from AI, retrieval, recommendations, Today plans, Ask AI, analytics, embeddings, and future outputs. | Missing |
| Provider retention/training/deletion approval | Provider contracts and terms are approved for retention, logging, training-use, deletion, subprocessors, transfers, security, and incident response. | Missing / not approved |
| Embedding invalidation evidence | Tests show embeddings are invalidated or deleted when source memory is deleted, edited, rejected, expired, archived, or consent is withdrawn. | Missing |
| AI evaluation harness results | Harness results demonstrate evidence citation/explanation, draft status, non-clinical language, refusal behaviour, excluded-data handling, and safe boundaries. | Missing |
| Red-team/refusal tests | Tests cover therapy, diagnosis, treatment, crisis, emergency monitoring, legal, medical, financial, addiction, professional advice, and unsafe reliance prompts. | Missing |
| User correction flow | Evidence shows users can correct, reject, delete, and withdraw memory or AI-derived content. | Missing |
| Audit trail | Approved minimal audit trail for memory confirmation, deletion, embedding invalidation, provider processing, and AI safety review without sensitive free text. | Missing / not approved |

## Non-Negotiable AI Boundaries

- AI outputs are drafts.
- Users remain decision-makers.
- Durable memory requires explicit confirmation.
- Crisis/safety content must not become product memory.
- AI must cite or explain confirmed user context where recommendations are generated.
- AI provider approval is required before live user data processing.
