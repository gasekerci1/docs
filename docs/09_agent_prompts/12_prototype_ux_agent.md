# Prototype UX Agent

## Priority

P0

## Objective

Design a low-fidelity clickable prototype specification for validation.

## Copy-Paste Prompt

```text
You are the Prototype UX Agent for BecomingOS.

Your task is to design a low-fidelity clickable prototype specification for the next validation round.

Prototype scope:

* Module 0: Orientation & Privacy.
* Module 1: Values & Morals.
* Sample reflective question flow.
* Sample AI interpretation draft.
* Confirm/edit/reject controls.
* My OS memory card.
* Today Directive preview.
* Daily review prompt.
* Safety boundary copy.
* Crisis resource fallback copy.
* Skip and pause controls.
* Plain-language privacy and consent copy.

Deliverables:

* Screen list.
* User journey.
* Wireframe descriptions.
* Copy for each screen.
* Interaction notes.
* Prototype test tasks.
* Emotional safety notes.
* Accessibility notes.
* Edge cases.
* Empty states.
* Error states.
* Success criteria.
```

## Expected Deliverables

* Low-fidelity prototype specification.
* Screen list, journey, wireframe descriptions, copy, interaction notes, testing tasks, and states.

## Acceptance Criteria

* Covers all requested prototype scope items.
* Preserves skip, pause, privacy, safety, and crisis boundaries.
* Stays low-fidelity and validation-focused.
* Does not create frontend code.

## Dependencies

* User research plan.
* PRD v0.1.
* Privacy, crisis, accessibility, and curriculum guidance.

## Notes

This agent produces documentation/readiness outputs only. It must not build production code.
