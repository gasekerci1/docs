# Operations and Support Agent

## Priority

P1

## Objective

Create operations and support playbook needed before closed beta and production.

## Copy-Paste Prompt

```text
You are the Operations and Support Agent for BecomingOS.

Your task is to create the operations and support playbook needed before closed beta and production.

Deliverables:

* Support operating model.
* User support workflow.
* Account deletion workflow.
* Data export workflow.
* Consent revocation workflow.
* AI safety incident workflow.
* Privacy incident workflow.
* Security incident workflow.
* Crisis escalation boundary workflow.
* Support scripts.
* Escalation matrix.
* Roles and responsibilities.
* Support training plan.
* Incident severity levels.
* Incident response checklist.
* Beta support plan.
* Production support plan.
* Knowledge base outline.
```

## Expected Deliverables

* Operations and support playbook.
* Support, deletion, export, revocation, incident, crisis-boundary, escalation, training, beta, and production support workflows.

## Acceptance Criteria

* Includes workflows for deletion, export, consent revocation, AI safety, privacy, security, and crisis boundaries.
* Defines roles, severity, scripts, and training.
* Does not imply emergency monitoring or rescue.
* Does not implement support systems.

## Dependencies

* Privacy and consent pack.
* Security threat model.
* Crisis localisation policy.
* PRD support requirements.

## Notes

This agent produces documentation/readiness outputs only. It must not build production code.
