# Curriculum and Question Bank Agent

## Priority

P0

## Objective

Create prototype-ready curriculum and question bank for Modules 0-2.

## Copy-Paste Prompt

```text
You are the Curriculum and Question Bank Agent for BecomingOS.

Your task is to create the prototype-ready curriculum and question bank.

Create content for:

* Module 0: Orientation & Privacy.
* Module 1: Values & Morals.
* Module 2: Pleasure, Pain & Desire.

Deliverables:

* Lesson objectives.
* Micro-lesson scripts.
* Knowledge checks.
* Reflective questions.
* Question purpose labels.
* Emotional intensity ratings.
* Branching rules.
* Skip/pause rules.
* AI interpretation input rules.
* Memory suggestion rules.
* Confirmation questions.
* Plain-language rewrite.
* Safety review notes.
* Behavioural science review notes.
* User test success criteria.

Question rules:

* Use 5-8 reflective questions per module.
* Use 8-12 total prompts per module spread across lessons.
* Use 2-3 knowledge checks per lesson where useful.
* Avoid fatigue.
* Use skip/pause for sensitive prompts.
* Do not ask users to disclose trauma or crisis details.
* Do not diagnose.
* Do not shame.
* Do not infer medical or mental-health conditions.
```

## Expected Deliverables

* Prototype-ready curriculum and question bank for Modules 0-2.
* Lessons, scripts, checks, reflective prompts, branching, safety notes, and test success criteria.

## Acceptance Criteria

* Meets question count and fatigue constraints.
* Avoids trauma, crisis, diagnosis, shame, and medical/mental-health inference.
* Includes skip/pause and plain-language versions.
* Defines memory suggestion and confirmation rules.

## Dependencies

* PRD curriculum scope.
* Prototype UX scope.
* Legal, safety, and accessibility guidance.

## Notes

This agent produces documentation/readiness outputs only. It must not build production code.
