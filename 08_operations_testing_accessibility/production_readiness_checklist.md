# Production Readiness Checklist

Current status: production readiness planning checklist only.

Current production status: NO-GO.

This checklist does not approve private beta, public MVP build, production readiness, public launch, implementation, or compliance claims.

## Stage Separation

- Documentation planning is active.
- Private beta is NO-GO until owner approvals and evidence are complete.
- Public MVP/build is NO-GO until public MVP gates are complete.
- Production is NO-GO until production gates are complete.

## Product Gates

- [ ] Final production product scope approved.
- [ ] Non-goals and prohibited claims reviewed.
- [ ] Public MVP evidence reviewed and accepted.
- [ ] Private beta learnings reviewed, if beta runs.
- [ ] User research and market validation completed.

## Legal, Privacy, And Safety Gates

- [ ] Final legal claims review completed.
- [ ] Privacy impact assessment completed.
- [ ] Final consent/data governance approved.
- [ ] Production privacy policy and user-facing notices approved.
- [ ] Retention, deletion, export/access, and withdrawal process evidenced.
- [ ] Crisis/signposting policy approved.
- [ ] Support boundaries approved.
- [ ] No compliance claims made without review.

## AI Gates

- [ ] AI role boundary approved.
- [ ] AI provider contracts/approval completed.
- [ ] AI evaluation harness results completed.
- [ ] Red-team/refusal tests completed.
- [ ] Memory/retrieval/embedding deletion tests completed.
- [ ] User correction flow evidenced.
- [ ] AI audit trail approved.

## Security And Architecture Gates

- [ ] Security review completed.
- [ ] Threat model closed or risk-accepted.
- [ ] Architecture decision record approved.
- [ ] Data storage model approved.
- [ ] Auth/access control model approved.
- [ ] Backup/recovery planning approved.
- [ ] Monitoring/logging policy approved.
- [ ] Incident response integration approved.

## NFR, Testing, And Accessibility Gates

- [ ] Production NFRs approved.
- [ ] Reliability/availability plan approved.
- [ ] Performance and load evidence completed.
- [ ] Testing results completed.
- [ ] Accessibility QA evidence completed.
- [ ] Data rights workflow tests completed.
- [ ] Analytics/privacy review completed.

## Operations, Support, And Release Gates

- [ ] Incident response plan approved.
- [ ] Support operations plan approved.
- [ ] Support staffing and escalation owners approved.
- [ ] Provider incident process approved.
- [ ] Public release go/no-go signed GO.

## Standing Rule

Production readiness requires completed evidence and signed owner approvals. Planning documents, readiness reports, private beta approval, and public MVP/build approval do not approve production.
